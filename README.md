# Товарный радар — облачный MVP

Цель этого пакета — развернуть интерфейс в браузере без установки программ на ноутбук и включить ежедневный сбор относительного поискового интереса.

## Бесплатное размещение

Рекомендуемый первый вариант: **Streamlit Community Cloud + GitHub**. Streamlit Community Cloud разворачивает приложение из GitHub и не требует локального Python. Бесплатный сервис может засыпать при отсутствии активности и имеет ограничения по ресурсам; это прототип, не production SLA.

1. Создайте аккаунт на GitHub и новый репозиторий, например `tovarny-radar`.
2. Распакуйте архив на ноутбуке обычным способом (не нужно устанавливать Python).
3. Загрузите все файлы и папки из архива в репозиторий GitHub через веб-интерфейс `Add file → Upload files`. Не загружайте `.git` или архив внутрь репозитория.
4. Откройте `https://share.streamlit.io/`, войдите через GitHub и нажмите **Create app**.
5. Выберите свой репозиторий, ветку `main`, основной файл `app.py`, затем Deploy.
6. Чтобы ежедневный сбор запускался автоматически, откройте вкладку **Actions** в репозитории и разрешите GitHub Actions, если GitHub попросит.

## Что уже автоматизировано

- веб-интерфейс рейтинга;
- расчёт юнит-экономики из загруженных данных;
- workflow GitHub Actions, который раз в сутки пытается получить индекс поискового интереса для списка запросов из `config/trend_keywords.txt`;
- сохранение снимков в `data/trends_history.csv` и `data/trends_latest.csv` в репозитории;
- интерфейс для просмотра последнего снимка и истории.

## Что НЕ является автоматическим пока

- приложение не находит все товары России самостоятельно;
- Google Trends даёт относительный индекс интереса, а не продажи и не абсолютный поисковый объём;
- цены и MOQ поставщиков 1688/Alibaba не загружаются автоматически: универсального бесплатного открытого API для всего китайского каталога нет;
- тарифы маркетплейсов, доставка, таможня, сертификация и рекламные расходы требуют отдельных проверяемых источников;
- строки `demo_products.csv` — синтетические примеры. Не используйте их для закупки.

## Обновление списка запросов

Редактируйте `config/trend_keywords.txt` прямо на GitHub — по одному запросу на строку. Не добавляйте слишком много запросов сразу: Google Trends может ограничивать автоматические обращения.

## Как читать данные

Индекс 0–100 нормирован внутри конкретного запроса и периода; сравнение разных запросов напрямую некорректно. Ошибки/лимиты Google Trends фиксируются в логе workflow. Если сбор не удался, приложение продолжит показывать последнюю сохранённую историю.

## Важное про бесплатный режим

GitHub Actions работает по расписанию с возможными задержками, а бесплатные облачные приложения могут засыпать. Поэтому это минимально затратный этап проверки гипотезы, а не гарантия непрерывной промышленной работы.
